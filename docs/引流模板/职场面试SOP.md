# 职场面试SOP - 从投递到入职的完整流程

## 一、面试前准备（提前3-7天）

### 1. 公司调研

- [ ] 公司官网、产品、业务模式
- [ ] 近期新闻、融资情况
- [ ] 竞品分析（至少了解2-3家）
- [ ] 企业文化、价值观

### 2. 岗位分析

- [ ] 重新研读JD，提取关键词
- [ ] 匹配自身经历，准备3-5个案例
- [ ] 准备"为什么选择这个岗位"的答案

### 3. 自我介绍准备

**公式：我是谁 + 我做过什么 + 我能带来什么**

```
模板：
"您好，我是XXX，有X年XX领域经验。
在上一家公司，我负责XXX，取得了XXX成果（用数据说话）。
我擅长XXX，这与贵公司的XXX需求很匹配。
希望能有机会为贵公司贡献我的XXX能力。"
```

### 4. 常见问题准备

- 你的优缺点是什么？
- 为什么离开上一家公司？
- 未来3-5年的职业规划？
- 期望薪资是多少？
- 你有什么问题想问我们？

### 5. 形象准备

- [ ] 着装得体（比公司日常着装正式一级）
- [ ] 提前测试线上面试设备（网络、摄像头、麦克风）
- [ ] 准备纸笔记录关键信息

---

## 二、面试中（当天）

### 1. 开场（前5分钟）

- 提前10-15分钟到达
- 主动握手（线下）或微笑打招呼（线上）
- 简短寒暄，保持自然

### 2. 核心环节（20-40分钟）

**STAR法则回答问题：**

- **S**ituation（情境）：当时的背景是什么？
- **T**ask（任务）：你的目标是什么？
- **A**ction（行动）：你具体做了什么？
- **R**esult（结果）：取得了什么成果？（用数据）

**示例：**
"在上一家公司（S），我负责提升用户留存率（T）。我主导了用户分层运营项目，建立了3级用户体系（A）。最终3个月内存留率提升了25%（R）。"

### 3. 提问环节（最后5-10分钟）

**推荐问题：**

- 这个岗位的核心挑战是什么？
- 团队目前的工作重点是什么？
- 公司对员工的成长支持如何？
- 下一步的面试流程是怎样的？

**避免问题：**

- 加班多吗？（可以委婉问工作节奏）
- 福利怎么样？（可以在offer阶段问）

## 三、面试后跟进

### 1. 当天

- [ ] 发送感谢邮件/消息（24小时内）
- [ ] 复盘面试表现，记录问题

**感谢邮件模板：**

```
主题：感谢您的时间 - XXX面试

XXX您好：

感谢您今天抽出时间面试我。通过交流，我对XXX岗位有了更深入的了解，
也更加确信我的XXX能力可以为团队带来价值。

特别是您提到的XXX，让我印象深刻。我会在后续持续学习这方面的知识。

期待能有进一步合作的机会。

祝好！
XXX
```

### 2. 3-5天后

- [ ] 如果没有反馈，可以礼貌跟进一次
- [ ] 继续投递其他岗位，保持选择权

---

## 四、薪资谈判

### 1. 了解市场行情

- 查看同岗位薪资范围（脉脉、看准网、Boss直聘）
- 了解目标公司的薪资结构

### 2. 谈判策略

- **不要先报价**，让对方先出牌
- **给出区间**，而非固定数字
- **强调价值**，而非需求（"基于我的经验和能力..."而非"我需要..."）

### 3. 谈判话术

```
"根据我的了解，这个岗位的市场薪资范围是XX-XX。
考虑到我的XXX经验和XXX能力，我期望的薪资是XX。
当然，我也很看重贵公司的发展机会，薪资方面可以商量。"
```

## 六、入职准备

- [ ] 确认入职时间、地点、所需材料
- [ ] 了解公司规章制度
- [ ] 准备入职第一周的工作计划
- [ ] 调整作息，保持良好状态

---

## 面试避坑指南

### ❌ 常见错误：

1. 迟到或不提前测试设备
2. 对公司一无所知
3. 回答没有重点，啰嗦
4. 说前公司/前领导坏话
5. 薪资期望过高或过低
6. 没有问题问面试官

### ✅ 加分项：

1. 带作品集或案例
2. 提到对公司产品的见解
3. 展现学习能力和成长意愿
4. 提问环节问有深度的问题
5. 面试后及时跟进
