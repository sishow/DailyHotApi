# 简历模板 - 让HR一眼看中你

## 一、简历基本结构

### 推荐顺序：

1. 基本信息
2. 求职意向
3. 个人优势（3-4句话）
4. 工作经历（倒序）
5. 项目经历（可选）
6. 教育背景
7. 技能/证书

---

## 二、各模块撰写指南

### 1. 基本信息

```
姓名：XXX
电话：138-XXXX-XXXX
邮箱：xxx@email.com
年龄：XX岁
工作年限：X年
现居地：XX市
```

**注意：**

- 邮箱用专业邮箱（QQ数字邮箱减分）
- 照片：职业照，不要自拍/生活照
- 不需要写：身高、体重、婚姻状况、政治面貌

---

### 2. 求职意向

```
求职岗位：产品经理
期望薪资：15-20K
期望城市：北京/上海
到岗时间：1个月内
```

**注意：**

- 求职意向要明确，不要写"管理类岗位"这种模糊描述
- 期望薪资可以写区间，留谈判空间

---

### 3. 个人优势（核心模块）

**公式：年限 + 核心能力 + 代表成果**

**示例：**

```
5年互联网产品经验，专注B端SaaS产品从0到1搭建。
主导过3个核心项目，累计服务客户500+，年营收增长200%。
擅长需求分析、产品规划、跨部门协作，有带团队经验。
```

**避坑：**

- ❌ "性格开朗、善于沟通、学习能力强"（太空洞）
- ✅ 用数据和成果说话

---

### 4. 工作经历（最重要）

**格式：**

```
公司名称 | 岗位 | 时间（YYYY.MM - YYYY.MM）

工作内容：
- 负责XXX，通过XXX方法，实现了XXX成果（数据）
- 主导XXX项目，协调X个部门，X个月内完成，获得XXX效果
- 优化XXX流程，效率提升XX%，成本降低XX%

核心业绩：
- 业绩1：具体成果（用数据）
- 业绩2：具体成果（用数据）
- 业绩3：具体成果（用数据）
```

**示例：**

```
XX科技有限公司 | 产品经理 | 2021.06 - 至今

工作内容：
- 负责公司核心SaaS产品规划，服务500+企业客户
- 主导产品从0到1搭建，3个月内上线，首月签约客户50家
- 建立用户反馈机制，用户满意度从70%提升至92%

核心业绩：
- 产品上线首年营收500万，第二年突破1500万
- 用户留存率从60%提升至85%
- 带领5人产品团队，获得公司年度优秀团队奖
```

**STAR法则：**

- **S**ituation（背景）：什么情况下？
- **T**ask（任务）：目标是什么？
- **A**ction（行动）：做了什么？
- **R**esult（结果）：成果是什么？（数据化）

---

### 5. 项目经历（可选）

**适合人群：**

- 工作经历中无法完全展示的项目
- 跨行业转行，需要展示相关经验
- 应届生，展示实习/校园项目

**格式：**

```
项目名称 | 角色 | 时间

项目背景：
简要说明项目背景和目标

我的职责：
- 负责XXX
- 协调XXX
- 优化XXX

项目成果：
- 成果1（数据）
- 成果2（数据）
```

---

### 6. 教育背景

```
XX大学 | XX专业 | 本科/硕士 | 20XX.09 - 20XX.06

- GPA：3.8/4.0（如果好的话写）
- 相关课程：XXX、XXX（如果与岗位相关）
- 荣誉奖项：XXX奖学金、XXX比赛X等奖
```

**注意：**

- 工作3年以上，教育背景简化
- 名校或高GPA可以加粗

---

### 7. 技能/证书

**格式：**

```
专业技能：
- 熟练使用Axure、Sketch、Figma等设计工具
- 精通SQL，能独立完成数据分析
- 熟悉Python，能编写简单脚本

语言能力：
- 英语：CET-6（580分），能流利阅读英文文档
- 日语：N2

证书：
- PMP项目管理证书
- 产品经理国际认证（NPDP）
```

## 四、简历优化清单

### ✅ 检查项：

- [ ] 篇幅控制在1-2页
- [ ] 没有错别字和语法错误
- [ ] 工作经历用数据说话
- [ ] 关键词与JD匹配
- [ ] 格式统一，排版清晰
- [ ] 导出为PDF格式
- [ ] 文件名：姓名-岗位-工作年限.pdf

### ❌ 常见错误：

- 篇幅过长（超过3页）
- 大段文字，没有重点
- 只写工作内容，不写成果
- 用"参与了"而不是"负责/主导"
- 照片不专业
- 邮箱用QQ数字邮箱

## 五、针对不同岗位的调整建议

### 产品经理：

- 突出产品思维、数据分析能力
- 展示从0到1的项目经验
- 强调用户洞察和需求分析

### 运营岗位：

- 突出数据增长、活动策划能力
- 展示具体的运营数据（GMV、DAU、转化率）
- 强调创意和执行力

### 技术岗位：

- 突出技术栈和项目经验
- 展示开源项目或技术博客
- 强调解决问题的能力和代码质量

### 设计岗位：

- 必须附带作品集
- 突出设计思维和审美能力
- 展示完整的设计流程

## 六、投递技巧

### 1. 邮件投递

**邮件标题：** 姓名-岗位-工作年限-手机号

**邮件正文：**

```
尊敬的HR：

您好！我是XXX，看到贵公司招聘XXX岗位，非常感兴趣。

我有X年相关经验，曾在XX公司负责XXX，取得了XXX成果。
我相信我的XXX能力可以为贵公司带来价值。

附件是我的简历，期待有机会进一步交流。

祝好！
XXX
138-XXXX-XXXX
```

### 2. 招聘平台投递

- 打招呼语不要只发"您好"
- 简短说明自己的核心优势
- 示例："您好，我有5年B端产品经验，主导过从0到1的项目，对这个岗位很感兴趣，期待交流。"
