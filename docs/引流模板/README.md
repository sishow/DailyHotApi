## 🚀 快速开始

### 场景1：准备找工作

1. 先看 [简历模板](./简历模板.md) → 优化你的简历
2. 再看 [面试题库](./面试题库.md) → 准备常见问题
3. 最后看 [职场面试SOP](./职场面试SOP.md) → 掌握完整流程

### 场景2：准备述职/晋升

1. 先看 [述职模板](./述职模板.md) → 学习述职框架
2. 参考模板撰写你的述职报告
3. 提前练习演讲

### 场景3：想增加收入

1. 先看 [副业指南](./副业指南.md) → 了解副业类型
2. 选择适合自己的副业方向
3. 按照SOP启动副业

### 场景4：想创业

1. 先看 [轻创业SOP](./轻创业SOP.md) → 了解轻创业模式
2. 评估自己的资源和能力
3. 选择合适的创业方向
4. 按照SOP启动项目
