# 845个工作群，845条无形的锁链

看到这条新闻的时候，我数了三遍——845个群。

不是845个好友，是845个工作群。

平均下来，她每天要盯着几百个群，生怕漏掉一条消息。下班？不存在的。周末？想都别想。

她的手机不是通讯工具，是24小时待命的电子镣铐。

更讽刺的是，她离职的方式——被踢出群。

没有告别，没有感谢，没有"辛苦了"。

就像删除一个过期的文件，干净利落。

**845个群，845次"收到"，845次"好的"，最后换来一个"您已被移出群聊"。**

这就是打工人的宿命。

你以为你在为公司卖命，公司只觉得你是可随时替换的零件。

845个群，没有一个是她的生活。

现在她终于自由了。

希望她能把这845个群的记忆，统统删掉。

**工作可以没有，但生活必须找回。**
